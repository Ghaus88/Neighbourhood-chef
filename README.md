# Neighbourhood Chef

A simple Next.js website where neighbours can list homemade food and others can order from them.

## Features

- Mobile responsive layout
- Navbar with routes for **About**, **Food Listings**, and **Neighbours**
- Home page CTA for browsing listings and finding local chefs
- Example food listing cards with order buttons

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
